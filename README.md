Sunshine City is an original open-world crime game in the browser: a sun-soaked procedural coastal city you explore on foot and by car, with traffic, pedestrians, a 0–5 star wanted system and police chases, pistol combat, and three story missions as Marco Reyes, a wheelman working for fixer Lena Cruz. Steal cars, outrun the heat, and finish the jobs — all rendered in three.js with a HUD, minimap, synth sound, and localStorage saves. No network requests; everything runs from local files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Drive with WASD, steal a parked car with E, shoot with the mouse, and follow the mission beacons.
